# 更新日志 & 迭代计划

这里记录了 ViteMind 的产品迭代历程和未来的开发计划。

## 📅 迭代计划 (Roadmap)

### 🚀 2025 Q1 - 核心功能增强
- [ ] **用户账户体系** - 支持用户注册、登录和个人中心
- [ ] **资源收藏功能** - 允许用户收藏喜欢的 AI 工具和设计资源
- [ ] **评论互动系统** - 用户可以对工具和资源进行评价
- [ ] **AI 智能推荐** - 基于用户偏好推荐相关工具

### 🛠 2024 Q4 - 基础建设 (进行中)
- [x] **AI 导航页面** - 完整的 AI 工具展示和搜索
- [x] **设计资源导航** - 独立的 UI/UX 资源页面
- [x] **自动化新闻抓取** - 基于 AI 的每日新闻生成
- [x] **性能优化** - 提升页面加载速度和 SEO

## 📝 更新日志 (Changelog)

### v1.4.0 (2025-12-29)
- ✨ **新增**: 全栈管理后台 (Admin Dashboard)，支持数据审核与管理
- 🔒 **安全**: 集成 Supabase Auth 和 RLS 策略，确保数据安全
- ♿ **无障碍**: 优化模态框 (Modal) 键盘导航和无障碍支持
- 🐛 **修复**: 优化新闻去重逻辑，解决重复生成问题
- 📚 **文档**: 新增 [构建全栈管理后台](/guide/tutorial/7-admin-dashboard) 技术教程

### v1.3.0 (2025-12-29)
- ✨ **新增**: 前端设计资源导航页面 (`/design-resources`)
- 🎨 **优化**: 重新设计资源展示布局，支持左侧分类导航
- 🔧 **功能**: 添加资源排序功能（名称、时间）
- 🗃️ **数据**: 初始化 20+ 个常用设计资源数据
- 🐛 **修复**: 解决 GitHub Pages 子路径部署导致的 404 问题

### v1.2.0 (2025-12-28)
- ✨ **新增**: AI 提示词库 (AI Prompts) 功能，支持瀑布流展示
- 🎨 **样式**: 全新品牌视觉升级，更新 Logo 和 Banner 设计
- ⚡ **性能**: 优化新闻抓取脚本，增加速率限制处理和 API 重试机制
- 🔧 **重构**: 统一环境变量前缀为 `SUPABASE_`，优化配置管理
- 🤖 **自动化**: 新增内容爬虫 (Content Crawler) 工作流

### v1.1.0 (2025-12-27)
- ✨ **新增**: AI 每日新闻自动化工作流
- ✨ **新增**: 集成 Supabase 数据存储，支持 AI 工具提交
- 🎨 **设计**: 首页改版为瑞士平面设计风格 (Swiss Style)
- 📊 **功能**: 新增 AI 新闻时间轴视图 (Timeline View)
- 📱 **优化**: AI 工具页重新设计为侧边栏布局，提升移动端体验
- 🐛 **修复**: 解决 AI 幻觉问题，优化新闻生成准确性

### v1.0.0 (2025-12-27)
- 🎉 **发布**: ViteMind 初始版本上线
- ✨ **功能**: AI 工具导航基础功能
- ✨ **功能**: 基础 AI 提示词库

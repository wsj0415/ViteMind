# 实战第五章：站在巨人的肩膀上

ViteMind 的诞生离不开开源社区的贡献。以下是我们在构建过程中参考的核心文档与资源。

## 📚 技术栈文档

*   **VitePress**
    *   [官方文档 (英文)](https://vitepress.dev/)
    *   [配置参考](https://vitepress.dev/reference/site-config)
    *   *这是构建本站的基石，建议通读 Guide 部分。*

*   **Vue.js 3**
    *   [官方文档 (中文)](https://cn.vuejs.org/)
    *   [组合式 API (Composition API)](https://cn.vuejs.org/guide/extras/composition-api-faq.html)
    *   *我们在编写自定义组件（如 NewsGallery）时大量使用了 `script setup` 语法。*

*   **GitHub Actions**
    *   [GitHub Actions 文档](https://docs.github.com/en/actions)
    *   [Python Setup Action](https://github.com/actions/setup-python)
    *   *自动化新闻抓取的幕后英雄。*

## 🎨 设计灵感

*   **Swiss Style (国际主义设计风格)**
    *   [Swiss Style Design History](https://www.printmag.com/design-history/swiss-style-principles-typefaces-designers/)
    *   *核心理念：网格系统 (Grid Systems)、非对称布局、无衬线字体 (Sans-serif)。*

*   **配色参考**
    *   **VitePress Default Theme**: 我们沿用了 VitePress 优秀的深色模式适配。
    *   **High Contrast**: 在“AI 军火库”和“订阅页”中，我们使用了高对比度的黑白配色，致敬经典瑞士平面设计。

## 🛠️ 实用工具

*   **Formspree**: [https://formspree.io/](https://formspree.io/) (无后端表单服务)
*   **OpenAI API**: [https://platform.openai.com/](https://platform.openai.com/) (新闻摘要生成)
*   **FeedParser**: [Python RSS 解析库](https://pythonhosted.org/feedparser/)
